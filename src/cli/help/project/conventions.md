# Conventions

`element-id-naming` of the `.bpmnlintrc` sets the prefix and case of new ids; without it the rule's defaults hold. Existing ids never change.

```text
bpmn conventions order.bpmn
```

A taken id gets a number and `W_ID_SUFFIXED`. A flow named after its ends follows them when they change. `bpmn guide ids` has the shapes.
