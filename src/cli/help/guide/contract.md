# Contract

- You change the model; shapes, edges and coordinates are never yours. To change the picture, name other elements: `bpmn guide format`.
- A write rewrites only what it changed; comments and attribute order stay. A result equal to the file is not written.
- A write that adds an error is refused and the file stays; `--force` writes anyway. Errors the file already had never block.
- New ids speak: `userTask_checkInvoice`. `--id` wins.
